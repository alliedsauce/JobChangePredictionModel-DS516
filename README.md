# Job Change Prediction Model
โปรเจกต์นี้เป็นการวิเคราะห์ข้อมูลเชิงสำรวจ (Exploratory Data Analysis: EDA) และสร้างโมเดล Machine Learning สำหรับการทำนายการเปลี่ยนงานของพนักงาน (JobChange Prediction)
โดยใช้ข้อมูลเชิงบุคคล ระดับการศึกษา ประสบการณ์ทำงาน ประเภทบริษัท ไปจนถึงข้อมูลเชิงพื้นที่ เช่น ดัชนีพัฒนาเมือง

---

## 🧠 **Background**
- ชุดข้อมูลประกอบไปด้วย
  - ข้อมูลการย้ายงานของพนักงาน รวมถึงปัจจัยต่าง ๆ ทั้งหมด 19,158 record
  - ตัวแปรเป้าหมาย คือ JobChange (0 = ไม่เปลี่ยนงาน, 1 = เปลี่ยนงาน) 
  - พบว่ามี class imbalance ของ JobChange อย่างชัดเจน ดังนี้ 0 = 75.07% และ 1 = 24.93%
  - ปัจจัยด้านต่าง ๆ เช่น ระดับการศึกษา (education_level) ประสบการณ์ทำงาน (experience) ความสอดคล้องของงานกับประสบการณ์ (relevent_experience) เป็นต้น
  - Data Sources ข้อมูลจาก [www.kaggle.com](https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists)

---

## 🧠 **Problem Statement**
องค์กรจำนวนมากประสบปัญหาการเปลี่ยนงานของพนักงาน (Job Change / Turnover) ซึ่งส่งผลให้เกิดต้นทุนด้านการสรรหา การอบรม และสูญเสียผลผลิตอย่างมีนัยสำคัญ
การคาดการณ์ความเป็นไปได้ที่พนักงานจะเปลี่ยนงานล่วงหน้าจึงเป็นสิ่งสำคัญต่อการวางแผนด้านทรัพยากรบุคคลและกลยุทธ์การรักษาพนักงาน (Retention Strategy)

---

## 🎯 **Objectives/SMART Objectives**
**Objectives**
1. ทำความสะอาดข้อมูลและจัดเตรียมข้อมูลให้พร้อมสำหรับการสร้างโมเดล
2. วิเคราะห์คุณสมบัติของข้อมูลและความสัมพันธ์ของการเปลี่ยนงานของพนักงาน
3. ทดสอบสมมติฐานเพื่อประเมินปัจจัยที่มีศักยภาพในการทำนาย
4. สร้างโมเดลพื้นฐาน เช่น Logistic Regression และ SVM
5. วัดและประเมินผลโมเดลด้วย Confusion Matrix Precision-Recall F1 Score และ ROC‑AUC
6. เพื่อสนับสนุนการวางนโยบายหรือกลยุทธ์ในการรักษาพนักงาน 

**SMART Objectives**

พัฒนาแบบจำลองการทำนายโอกาสการเปลี่ยนงานของพนักงาน โดยอาศัยการวิเคราะห์ปัจจัยสำคัญที่ส่งผลต่อพฤติกรรมการเปลี่ยนงาน พร้อมทั้งประเมินประสิทธิภาพของโมเดล ให้แล้วเสร็จภายในระยะเวลา 1 เดือน 
เพื่อสนับสนุนองค์กรในการกำหนดนโยบายและกลยุทธ์ด้านการรักษาพนักงานบนพื้นฐานของหลักฐานเชิงข้อมูลที่เชื่อถือได้

## 🧹 **Data Cleansing**
**1. Missing Values**
   จากการตรวจสอบพบว่ามีอยู่ 8 Attribute ที่มีค่า Null ดังนี้
   - gender จำนวน 4,508 Records คิดเป็น 23.53% MAR
   - enrolled_university จำนวน 386 Records คิดเป็น 2.01% MAR
   - education_level จำนวน 460 Records คิดเป็น 2.40% MAR
   - major_discipline จำนวน 2,813 Records คิดเป็น 14.68% MAR
   - experience จำนวน 65 Records คิดเป็น 0.34% MCAR/MAR (เล็กน้อย)
   - company_size จำนวน 5,938 Records คิดเป็น 30.99% MNAR / MAR โดยนัย
   - company_type จำนวน 6,140 Records คิดเป็น 32.05% MNAR / MAR โดยนัย
   - last_new_job จำนวน 423 Records คิดเป็น 2.21% MAR

**แนวทางการจัดการ Missing Values**

### Missing Values: gender
Attribute `gender` มีค่า Missing จำนวน 4,508 รายการ (23.53% ของข้อมูลทั้งหมด) ซึ่งถือเป็นสัดส่วนที่สูงและอาจส่งผลต่อความแม่นยำของโมเดลทำนายได้
ข้อมูลที่หายไปมีแนวโน้มเป็นประเภท **MAR (Missing At Random)** โดยมีความเป็นไปได้ว่าการหายไปอาจเกี่ยวข้องกับคุณลักษณะอื่นภายในชุดข้อมูล เช่น ประเภทบริษัทหรือเมืองที่พนักงานสังกัด 
ไม่ใช่การหายแบบสุ่มและไม่ใช่การหายเพราะเหตุปัจจัยของตัวแปรเพศเอง เพื่อหลีกเลี่ยงความเอนเอียงของข้อมูลและเพื่อให้โมเดลสามารถเรียนรู้รูปแบบของ Missing ได้อย่างถูกต้อง จึงเพิ่มหมวด “Unknown” สำหรับกรณีที่เพศไม่ถูกระบุ

### Missing Values: enrolled_university
Attribute `enrolled_university` มีค่า Missing จำนวน 386 รายการ (2.01% ของข้อมูลทั้งหมด) ซึ่งถือเป็นระดับที่ต่ำและไม่ส่งผลต่อความสมดุลของข้อมูลโดยรวม อย่างไรก็ตาม การหายไปของข้อมูลส่วนนี้มีแนวโน้มเป็นประเภท 
**MAR (Missing At Random)** เนื่องจากอาจสัมพันธ์กับคุณลักษณะอื่น เช่น ระดับการศึกษา (education_level) และประสบการณ์ทำงาน (experience) มากกว่าจะเป็นการหายแบบสุ่มทั้งหมด
เพื่อไม่ให้ความหมายของข้อมูลผิดเพี้ยนและเพื่อรักษาความถูกต้องของโมเดลจึงเพิ่มหมวด “Unknown” สำหรับกรณีที่ไม่ระบุข้อมูลการลงทะเบียนเรียน 

### Missing Values: education_level
Attribute `education_level` มีค่า Missing จำนวน 460 รายการ (2.40% ของข้อมูลทั้งหมด) ซึ่งอยู่ในระดับที่ไม่สูงมาก แต่ยังเพียงพอที่จะทำให้การกระจายระดับการศึกษาในชุดข้อมูลคลาดเคลื่อน
โดย Missing ของตัวแปรนี้มีแนวโน้มเป็นประเภท **MAR (Missing At Random)** เนื่องจากระดับการศึกษามักมีความสัมพันธ์กับตัวแปรอื่น เช่น สาขาวิชา (major_discipline) หรือประสบการณ์ทำงาน (experience) 
ไม่ใช่การหายไปแบบสุ่มสมบูรณ์ เพื่อป้องกันการบิดเบือนของข้อมูลและรักษาความถูกต้องในการสร้างโมเดลจึงเพิ่มหมวด “Unknown” สำหรับกรณีที่ไม่ระบุข้อมูลระดับการศึกษา

### Missing Values: major_discipline
Attribute `major_discipline` มีค่า Missing จำนวน 2,813 รายการ (14.68% ของข้อมูลทั้งหมด) ซึ่งถือเป็นสัดส่วนที่ค่อนข้างสูง และอาจส่งผลต่อความถูกต้องของแบบจำลอง ลักษณะของข้อมูลที่หายไปมีแนวโน้มเป็นแบบ 
**MAR (Missing At Random)** เนื่องจากการมีหรือไม่มีสาขาวิชา (Major) มักสัมพันธ์กับระดับการศึกษา (`education_level`) เช่น ผู้ที่จบระดับ Primary School หรือ High School มักไม่มีการระบุสาขาวิชาโดยธรรมชาติ
ของระบบการศึกษา หรืออาจไม่เกี่ยวข้องกับโปรแกรมการเรียนรู้ที่ใช้เก็บข้อมูลชุดนี้ 
เพื่อป้องกันการบิดเบือนของข้อมูลและรักษาความถูกต้องในการสร้างโมเดลจึงจัดการ Missing ใน 2 ประเด็นดังนี้
1. หาก `education_level` อยู่ในกลุ่มที่ *ปกติไม่มีสาขา* คือ Primary School หรือ High School ปรับเป็น No Major
2. เพิ่มหมวด “Unknown” สำหรับกลุ่มที่เหลือ

### Missing Values: experience
Attribute `experience` มีค่า Missing จำนวน 65 รายการ (0.34% ของข้อมูลทั้งหมด) ซึ่งถือเป็นสัดส่วนที่ต่ำมากและไม่น่าก่อให้เกิดความผิดเพี้ยนของข้อมูลในภาพรวม
ลักษณะข้อมูลที่หายไปมีแนวโน้มอยู่ในกลุ่ม **MCAR (Missing Completely At Random)** เนื่องจากจำนวน Missing มีน้อยมากและไม่พบรูปแบบการกระจุกตัวที่สัมพันธ์กับปัจจัยอื่นอย่างชัดเจน 
จึงแทนค่า missing ด้วย 0 ปี หรือไม่มีประสบการณ์

### Missing Values: company_size
Attribute `company_size` มีข้อมูลที่ไม่สามารถระบุได้จำนวน 5,938 รายการ (30.99% ของข้อมูลทั้งหมด) ซึ่งถือเป็นสัดส่วนที่สูงมาก ลักษณะดังกล่าวสะท้อนว่า Missing มีแนวโน้มอยู่ในประเภท **MNAR (Missing Not At Random)** 
เนื่องจากการไม่เปิดเผยขนาดองค์กรอาจเกิดจากเงื่อนไขหรือการตั้งใจปกปิดข้อมูลของบริษัทบางประเภทมากกว่าจะเป็นการหายแบบสุ่ม
ด้วยเหตุนี้ จึงการจัดการ Missing ของตัวแปร `company_size` ด้วยการเพิ่มหมวด “Unknown”

### Missing Values: company_type
Attribute `company_type` มีข้อมูลที่ไม่สามารถระบุประเภทองค์กรได้จำนวน 6,140 รายการ (32.05% ของข้อมูลทั้งหมด) ซึ่งถือเป็นสัดส่วนที่สูงมากและส่งผลโดยตรงต่อความน่าเชื่อถือของการวิเคราะห์ด้านโครงสร้างองค์กร
และพฤติกรรมการเปลี่ยนงาน ลักษณะดังกล่าวสะท้อนว่าการหายไปของข้อมูลอยู่ในกลุ่ม **MNAR (Missing Not At Random)** กล่าวคือ เหตุผลที่องค์กรไม่เปิดเผยประเภทของบริษัทอาจมาจากความตั้งใจหรือข้อจำกัดของข้อมูลต้นทาง
เช่น บริษัทสตาร์ทอัป บริษัทขนาดเล็ก หรือองค์กรที่ไม่อยู่ในระบบมาตรฐาน ทำให้ไม่สามารถจัดหมวดได้ชัดเจน จึงการจัดการ Missing ของตัวแปร `company_type` ด้วยการเพิ่มหมวด “Unknown”

### Missing Values: last_new_job
Attribute `last_new_job` มีข้อมูลที่หายไปจำนวน 423 รายการ (2.21% ของข้อมูลทั้งหมด) ซึ่งถือว่าอยู่ในระดับปานกลางและมีความสำคัญ เนื่องจากตัวแปรนี้สะท้อนจำนวนปีตั้งแต่พนักงานเคยย้ายงานครั้งสุดท้าย 
ซึ่งเป็นข้อมูลที่มีนัยสำคัญต่อการทำนายพฤติกรรมการเปลี่ยนงาน (`JobChange`) โดยตรง รูปแบบของ Missing มีแนวโน้มเป็นประเภท **MAR (Missing At Random)** เนื่องจากความเป็นไปได้ของการขาดหายอาจเชื่อมโยงกับปัจจัยอื่น
เช่น ประสบการณ์ทำงาน (`experience`), ขนาดองค์กร (`company_size`) หรือการมีประสบการณ์ที่เกี่ยวข้อง (`relevent_experience`) ทำให้การหายไปไม่ได้เป็นแบบสุ่มสมบูรณ์ แต่สัมพันธ์กับกลุ่มข้อมูลบางประเภท
แนวทางการจัดการ เช่น เติมค่ามัธยฐานของ `last_new_job` ภายในกลุ่มที่มีประสบการณ์ (`experience`) ใกล้เคียงกัน  

1. **เติมค่าด้วยค่ากลางหรือค่าที่พบมากที่สุดภายในกลุ่มที่เกี่ยวข้อง (Group-wise Imputation)**  
   - เช่น เติมค่ามัธยฐานของ `last_new_job` ภายในกลุ่มที่มีประสบการณ์ (`experience`) ใกล้เคียงกัน  
   - ลดความเอนเอียงของข้อมูลและคงความสมเหตุสมผลของตัวแปร

2. **จัดกลุ่มค่า (Binning) ก่อนทำการ Impute**  
   - เช่น แบ่งเป็นช่วง 0–1 ปี, 2–3 ปี, 4–5 ปี, มากกว่า 5 ปี  
   - แล้วเติมค่าตามกลุ่มเพื่อสะท้อนโครงสร้างการย้ายงานได้ดีขึ้น

3. **สร้างตัวแปรกำกับ (`last_new_job_missing_flag`)**  
   - เพื่อรักษาข้อมูลว่าค่าที่หายไปอาจมีความหมายเชิงพฤติกรรม เช่น กลุ่มที่ไม่มีข้อมูลการย้ายงานอาจเป็นผู้ที่เพิ่งเข้าสู่ตลาดแรงงานหรือมีรูปแบบอาชีพที่แตกต่าง

ไม่แนะนำให้แทนค่าด้วยตัวเลขแบบตรงไปตรงมา เช่น 0 หรือค่าเฉลี่ยรวมของชุดข้อมูล เนื่องจากอาจทำให้การกระจายของข้อมูลบิดเบือนและลดความแม่นยำของแบบจำลองในระยะยาว
